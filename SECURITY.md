# Security Policy

## Supported Versions

Security updates are applied to the latest version on the default branch.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, email: **security@median.example.com** (replace with your preferred security contact).

Include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

You can expect an initial response within 5 business days.
