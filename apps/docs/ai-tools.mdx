---

Any AI tool that can run shell commands works with Median. Here's how to set up the most popular ones.

## Claude Code

`mdn setup` automatically adds instructions to `CLAUDE.md`. No manual config needed.

```bash
mdn setup
```

## Cursor

Add to `.cursorrules` or your project rules file:

```markdown
## Task management

Use the Median CLI to manage tasks:
- Check tasks: `mdn tasks --agent cursor`
- Pick up: `mdn status <CODE> in_progress --agent cursor`
- Complete: `mdn status <CODE> ready --agent cursor`
- Create: `mdn create --title "..." --agent cursor`
```
