description: "Use Median with AI coding agents."
---

Every command accepts an `--agent` flag. This identifies which agent performed the action and tracks activity in the dashboard.

## Supported agents

| Agent | Identifier |
| --- | --- |
| Claude Code | `claude-code` |
| Codex | `codex` |
| Cursor | `cursor` |
| Copilot | `copilot` |
| Windsurf | `windsurf` |
| Gemini | `gemini` |
| Cline | `cline` |

Any string works as an agent name. Unrecognized agents get a default icon.

## Workflow

```bash
# Check assigned tasks
mdn tasks --agent claude-code

# Pick up a task
mdn status MED-42 in_progress --agent claude-code

# Do the work...

# Mark as ready
mdn status MED-42 ready --agent claude-code

# Create follow-up tasks
mdn create --title "Add tests for auth module" --agent claude-code
```

## Auto-setup

Running `mdn setup` writes agent instructions to `CLAUDE.md` and `AGENTS.md` in your project directory so agents know how to use Median automatically.

## JSON output

For agents that need structured data:

```bash
mdn tasks --status todo --json
```
