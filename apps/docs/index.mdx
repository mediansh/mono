Median is a shared task system for product teams, developers, and coding agents.
It combines a web workspace, a task board, integrations, API keys, and a CLI so feedback can flow in from the tools you already use and ship back out through the same system.

## What Median Does

- Collect feedback and work from channels like Discord, GitHub, Linear, and X into one task board.
- Let humans and agents work from the same queue using the web app or the `mdn` CLI.
- Track ownership with agent attribution, workspace roles, labels, priorities, and task status.
- Keep an audit trail of changes, webhook activity, member events, and AI-generated work.

## Typical Workflow

<Steps>
  <Step title="Create a workspace">
    Start in the web app and create a workspace for your team.
  </Step>
  <Step title="Connect your stack">
    Add integrations like Linear, GitHub, Discord, X, or generate API keys for the CLI.
  </Step>
  <Step title="Triage work">
    Review incoming requests on the board, organize them with labels and priority, and move them through the workflow.
  </Step>
  <Step title="Work from anywhere">
    Update tasks from the dashboard, terminal, or an AI coding agent using `mdn`.
  </Step>
  <Step title="Ship with context">
    Use logs, source links, and development references to understand what changed and why.
  </Step>
</Steps>

## Quick start

<Steps>
  <Step title="Install">
    ```bash
    npm install -g @mediansh/cli
    ```
  </Step>
  <Step title="Connect your workspace">
    ```bash
    mdn setup
    ```
    Paste your API key from [Settings > API Keys](https://median.sh) when prompted.
  </Step>
  <Step title="List your tasks">
    ```bash
    mdn tasks
    ```
  </Step>
</Steps>
