Median is a task management platform built for modern development workflows. The `mdn` CLI lets you create, track, and update tasks without leaving your terminal — and it works just as well for AI agents as it does for humans.

## Why Median?

<Columns cols={3}>
  <Card title="Agent-native" icon="robot">
    Every command supports an `--agent` flag. Agents can pick up tasks, update statuses, and create new work autonomously.
  </Card>
  <Card title="CLI-first" icon="terminal">
    No browser required. List, create, and update tasks from the command line with a single binary.
  </Card>
  <Card title="Real-time sync" icon="arrows-rotate">
    Changes sync instantly to the Median dashboard and across your entire team.
  </Card>
</Columns>

## Quick start

Get up and running in under a minute.

<Steps>
  <Step title="Install the CLI">
    ```bash
    npm install -g @mediansh/cli
    ```
  </Step>
  <Step title="Connect your workspace">
    ```bash
    mdn setup
    ```
    Paste your API key when prompted. You can find it in your [Median dashboard](https://median.sh) under workspace settings.
  </Step>
  <Step title="List your tasks">
    ```bash
    mdn tasks
    ```
  </Step>
</Steps>

## For AI agents

Median is designed to work with AI coding agents like Claude Code, Cursor, Copilot, and more. Agents identify themselves with the `--agent` flag, and their activity is tracked across the dashboard.

```bash
# Agent picks up a task
mdn status MED-42 in_progress --agent claude-code

# Agent completes the task
mdn status MED-42 ready --agent claude-code
```
