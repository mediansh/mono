## Install via npm

The fastest way to install `mdn` is through npm.

```bash
npm install -g @mediansh/cli
```

Verify the installation:

```bash
mdn --version
```

## Platform support

The CLI ships pre-built binaries for:

| Platform | Architecture |
| --- | --- |
| macOS | x64, arm64 (Apple Silicon) |
| Linux | x64, arm64 |
| Windows | x64 |

## Next steps

Once installed, connect the CLI to your workspace:

```bash
mdn setup
```

See the [setup guide](/cli/setup) for details.
