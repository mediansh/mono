## Install

```bash
npm install -g @mediansh/cli
```

Verify it worked:

```bash
mdn --version
```

## Supported platforms

| Platform | Architecture |
| --- | --- |
| macOS | x64, arm64 (Apple Silicon) |
| Linux | x64, arm64 |
| Windows | x64 |

## Next step

```bash
mdn setup
```

See the [setup guide](/cli/setup) to connect your workspace.
