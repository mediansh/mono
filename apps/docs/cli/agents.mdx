title: "Agent integration"
description: "Use Median with AI coding agents."
---

Median is designed for AI agents. Every command accepts an `--agent` flag that identifies which agent performed the action, and activity is tracked across the dashboard.

## Supported agents

The CLI recognizes these agents and displays their icons in task listings:

| Agent | Icon | Identifier |
| --- | --- | --- |
| Claude Code | ⚡ | `claude-code` |
| Codex | 🔎 | `codex` |
| Cursor | ▸ | `cursor` |
| Copilot | ◯ | `copilot` |
| Windsurf | 🏄 | `windsurf` |
| Gemini | ♦ | `gemini` |
| Cline | ◆ | `cline` |
| Other | 🤖 | _(any string)_ |

You can pass any string as the agent name — unrecognized agents get the default robot icon.

## Setup for agents

When you run `mdn setup`, the CLI optionally writes agent instructions to `CLAUDE.md` and `AGENTS.md` in your current directory. These files tell agents how to use the Median CLI.

The generated instructions include:

```markdown
## Median Tasks

Before starting work, check your assigned tasks:
mdn tasks --agent <your-agent-name>

When picking up a task:
mdn status <TASK-CODE> in_progress --agent <your-agent-name>

When completing a task:
mdn status <TASK-CODE> ready --agent <your-agent-name>
```

## Agent workflow

A typical agent workflow looks like this:

<Steps>
  <Step title="Check assigned tasks">
    ```bash
    mdn tasks --agent claude-code
    ```
  </Step>
  <Step title="Pick up a task">
    ```bash
    mdn status MED-42 in_progress --agent claude-code
    ```
  </Step>
  <Step title="Do the work">
    The agent performs the implementation, writes code, runs tests, etc.
  </Step>
  <Step title="Mark as ready">
    ```bash
    mdn status MED-42 ready --agent claude-code
    ```
  </Step>
  <Step title="Create follow-up tasks">
    ```bash
    mdn create --title "Add tests for auth module" --priority medium --agent claude-code
    ```
  </Step>
</Steps>

## JSON output for agents

Agents that need structured data can use the `--json` flag:

```bash
mdn tasks --status todo --json
```

This outputs raw JSON that can be parsed programmatically instead of the formatted table.
