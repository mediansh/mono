---
title: "mdn tasks"
description: "List and filter tasks in your workspace."
---

The `tasks` command lists all tasks in your Median workspace. Use flags to filter by status, priority, label, or agent.

## Usage

```bash
mdn tasks [flags]
```

## Flags

| Flag | Short | Description |
| --- | --- | --- |
| `--status <status>` | `-s` | Filter by task status |
| `--priority <priority>` | `-p` | Filter by task priority |
| `--label <label>` | `-l` | Filter by label |
| `--agent <name>` | | Identify the calling agent |
| `--json` | | Output raw JSON |

## Examples

```bash
# List all tasks
mdn tasks

# Filter by status
mdn tasks --status todo

# Filter by priority
mdn tasks --priority urgent

# Filter by label
mdn tasks --label bug

# Combine filters
mdn tasks --status in_progress --priority high

# Agent-identified listing
mdn tasks --agent claude-code

# Machine-readable output
mdn tasks --json
```

## Output format

The default output is a formatted table:

```
  Median Workspace Tasks

  Code         Title                                  Status          Priority    Agent
  ────────────────────────────────────────────────────────────────────────────────────────
  MED-42       Fix authentication bug                 In Progress     !! Urgent   ⚡ claude-code
  MED-43       Add dark mode support                  Todo            ↑ High
  MED-44       Update API documentation               Ready           ─ Medium

  3 tasks
```

### Status colors

| Status | Color |
| --- | --- |
| `requests` | Magenta |
| `todo` | Blue |
| `in_progress` | Yellow |
| `ready` | Cyan |
| `shipped` | Green |
| `archive` | Gray |

### Priority indicators

| Priority | Display |
| --- | --- |
| `urgent` | `!! Urgent` |
| `high` | `↑ High` |
| `medium` | `─ Medium` |
| `low` | `↓ Low` |
| `none` | `None` |

## JSON output

Pass `--json` to get machine-readable output, useful for piping into other tools:

```bash
mdn tasks --json | jq '.[] | .taskCode'
```
